# Fitness-First-Website-Project

A modern, responsive, and high-energy studio fitness website designed to showcase workout plans, specialized small-group classes, and premium membership management features.

## ✨ Features
- **Responsive Layout:** Optimized for desktop, tablets, and smartphones.
- **Dynamic UI Sections:** Includes Home/Hero, Specialized Classes Grid, Membership Pricing Tiers, and an interactive Contact form.
- **Modern Dark Theme:** Styled using a sleek dark palette accented with high-energy neon hues tailored for fitness brands.

## 🛠️ Technologies Used
- **HTML5:** Semantic markup structure.
- **CSS3:** Advanced flexbox/grid alignments, transition effects, CSS variables, and media queries for total responsiveness.

## 📦 How to Run Locally
1. Clone the repository.
2. Open `index.html` directly in any modern browser.
